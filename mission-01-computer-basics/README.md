## 1. Work completed
### Task 1.1 — IPOS: Playing a song

| Stage | What happens in my example? | Hardware / component |
|-------|-----------------------------|----------------------|
| Input | I click Play | Mouse / trackpad |
| Processing | The music app runs and the audio data is decoded | CPU, RAM |
| Output | Sound is played and the progress bar moves | Speakers, screen |
| Storage | The song file is kept on the drive | SSD |

### How my activity moves from input to storage

When I click on trackpad for playing a song, the trackpad captures it
and sends it to the computer. Then CPU processes it .The song played 
through the speaker  so I can hear . Finally, the song is saved on the
SSD,so it is still there after I close the app or turn off the computer .
