### Task 4.2 — Compiler vs interpreter

| Point | Compiler | Interpreter |
|-------|----------|-------------|
| When translation / execution happens | The whole program is translated into another form, often machine code, before it runs | The program is read and carried out at runtime, one instruction at a time |
| Typical output | A separate executable or machine-code file that can be run later | No separate file is needed; the program's result appears as it runs |
| One example | C, translated with the `gcc` compiler | Python, run with `python3` |
| One advantage | The compiled program usually runs faster | It is quick to test and change, because I can run the code straight away |
